¿Cómo puedo aportar?

  1. Crea una carpeta donde quieras guardar los archivos de esta página.
  2. Copia el enlace del repositorio: https://github.com/pavel77gs/simplemente-una-pagina-web.git
  3. Con git clone copia este repositorio.
  4. Si no puedes, lo más probable es que no estés añadido como colaborador/a, envía tu usuario de github al servidor de Discord.
  5. Haz los cambios que quieras, no te olvides de documentar cada uno mediante commits.
  6. Una vez hechos tus cambios, súbelo con git push -u origin main (para la rama principal)
  7. Disfruta de la página :)
  8. Para seguir añadiendo cambios, asegúrate de actualizar el repositorio en tu disco local: git pull -u origin main

Recomendaciones

  • Comprueba el estado del repositorio: git status
  • Comprueba las diferencias que no se han guardado: git diff
  • Asegurate de estar en la rama main con git branch. Si no es el caso, usa git branch -u main
  • Cualquier otra recomendación que tengas añádela aquí :)
